## Améliorations P0/P1 intégrées

**P0** — badges type de série (Échauffement/Normal/Drop set/Échec) sur les écrans de saisie/live ;
bandeau + badges de record personnel (PR) ; indicateur de synchronisation « Enregistré / Hors ligne — sync en attente » ;
suppression de série en direct (croix par ligne) ; démarrage à vide en mode live.

**P1** — supersets (connecteur visuel) ; RPE par série ; notes d'exercice ; filtres muscle + équipement
et CTA de création d'exercice personnalisé ; nouveaux graphiques d'historique (volume, meilleur poids, répétitions totales)
en plus du 1RM ; répartition musculaire et séries/semaine par groupe sur l'écran progrès.

Aucun item P2 implémenté (dossiers de routines, calendrier, bilans, wearables, mesures corporelles/photos).
