## Défauts corrigés

1. **Zones tactiles trop petites** dans la bibliothèque : boutons de filtres et fermeture mesuraient moins de 44 px. Ils mesurent maintenant 44 px, sans débordement à 430 px. Captures `27-library-before.png`, `27-library-after.png`.
2. **Zones tactiles trop petites** dans le live : boutons de type de série, effacement RPE, suppression d'une série et lien de retour. Ils mesurent maintenant au moins 44 px. La suppression a été revérifiée après correction (`15-live-after.png`, `15-live-after-delete.png`).
3. **Zones tactiles trop petites** dans la nouvelle séance : badges de type (30 px), champs de série (38 px), croix de suppression et effacement RPE (28 px). Ils mesurent maintenant au moins 44 px ; le connecteur superset reste visible (`05-superset-after.png`).
4. **Message trompeur dans le live libre** : un catalogue vide en ligne était annoncé « indisponible hors ligne ». L'état en ligne indique désormais « Le catalogue est vide pour le moment. » ; état vérifié avec une réponse catalogue vide (`24-live-empty-after.png`).
